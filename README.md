# Dafish

A classic Snake game built with HTML, CSS, and JavaScript. No dependencies or build step required.

Open `index.html` in a modern browser, or serve this directory with:

```sh
python3 -m http.server 8000
```

Use the **arrow keys** to steer, **Space** to pause or resume, and **Restart** to begin again. Eat food to earn 10 points; hitting a wall or your own body ends the game. Your best score is saved in your browser when local storage is available.
